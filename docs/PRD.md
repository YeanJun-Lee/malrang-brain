# PRD — 말랑 브레인 (데일리 두뇌 퍼즐)

작성: /ait:plan · 2026-10-23 · 상태: 초안 (확인 필요 항목 있음)

## 1. 한 줄 정의

토스 앱 사용자가 하루 몇 분 동안 스도쿠·노노그램·지뢰찾기를 오늘의 세트로 돌아가며 풀거나, 원하는 퍼즐만 골라 푼다.

## 2. 사용자와 문제

- 핵심 사용자: 출퇴근·쉬는 시간에 짧게 머리를 쓰고 싶은 토스 앱 사용자
- 지금 겪는 불편: 퍼즐마다 앱이 따로 있고 광고가 많다. "오늘은 뭘 풀지"를 매번 정해야 해서 습관이 이어지지 않는다.
- 이 미니앱이 바꾸는 것: 토스 앱 안에서 매일 정해진 짧은 세트를 풀고, 연속 기록으로 습관을 이어 간다.

## 3. 핵심 여정 (3~5스텝)

1. 진입: 토스 앱 검색·공유 링크(이후 알림)로 들어와 홈(오늘)을 본다.
2. "오늘의 세트 시작" → 퍼즐 3개(스도쿠 → 노노그램 → 지뢰찾기)를 차례로 푼다. 중간에 나가도 이어 풀기.
3. 결과: 퍼즐별 시간과 오늘 세트 완료, 연속 일수가 올라간다.
4. 자유 모드: 원하는 퍼즐·난이도만 골라 계속 푼다.
5. 재방문: 다음 날 새 세트가 열린다(날짜 기반). 연속 기록을 이어 가려고 돌아온다.

## 4. 화면 흐름

| 화면 | 목적 | 전환 |
|---|---|---|
| 홈(오늘) | 오늘의 세트 3개 진행 상태, 연속 일수, 시작/이어 풀기 | → 플레이 / → 자유 모드 / → 기록 / → 설정 |
| 자유 모드 | 퍼즐 종류 × 난이도 선택 | → 플레이 / ← 홈 |
| 플레이(스도쿠·노노그램·지뢰찾기) | 풀스크린 퍼즐 판 + 공통 상단(타이머·일시정지·규칙) | → 결과 / 일시정지 시트 / ← 홈 |
| 규칙 안내 | 퍼즐별 첫 진입 시 규칙 3줄 + 예시 | ← 플레이 |
| 결과 | 소요 시간, 오늘 세트의 다음 퍼즐 | → 다음 퍼즐 / → 홈 |
| 기록 | 달력(푼 날), 연속 일수, 종류별 최고 기록 | ← 홈 |
| 설정 | 사운드·햅틱 On/Off, 기록 초기화, 문의 | ← 홈 |

- 뒤로가기: 홈이 루트. 플레이 중 뒤로가기·안드로이드 백버튼 → 일시정지 + "나가기/계속" 선택, 진행은 자동 저장. 루트에서 닫기 → 종료 확인 모달(게임 출시 가이드 요건).
- 빈 상태/로딩: 첫 사용자는 홈에서 "오늘의 세트 시작" 하나만 크게. 퍼즐 생성 중에는 판 모양 스켈레톤.

## 5. SDK 도메인·권한

| 도메인 | 왜 필요한가 | 권한 | 거부 시 동작 |
|---|---|---|---|
| game | 게임 카테고리 사용자 식별(getUserKeyForGame), 기록을 사용자별로 저장 | — | 키를 못 받으면(구버전 등) 로컬 기록만 사용 |
| storage | 진행 중 판·연속 일수·기록·설정 로컬 저장 | — | — |
| navigation | 홈 ↔ 플레이 ↔ 결과·기록·설정 전환, 백버튼 처리 | — | — |
| haptic | 칸 확정·지뢰 발견·클리어 피드백 | — | 설정에서 끄기 |
| analytics | 세트 시작/완료, 퍼즐별 이탈 지점 로깅 (선택) | — | — |
| notification | (v1 제외) 매일 알림 — 진입 직후 동의 시트 금지, 설정에서만 | — (SDK 동의) | 알림 없이 사용 |

- 권한 없이도 되는 최소 기능: 전부. 런타임 기기 권한을 요청하지 않는다.

## 6. 데이터

- 저장 위치: 로컬(storage). 오늘의 퍼즐은 날짜를 시드로 클라이언트에서 생성 → 서버 없음.
- 서버가 필요한 부분: 기기 간 기록 동기화·친구 비교 — v1에서 뺀다.
- 개인정보: 수집하지 않는다. 게임 사용자 키(hash)만 로컬 키로 사용.

## 7. 수익화

- 모델: v1 없음. 이후 후보: 보상형 광고로 힌트 받기(IAA).
- 트리거되는 약관: BIZ_WORKSPACE(기본). 광고 도입 시 IAA.
- v1 포함 여부: 이후. 개인(비사업자) 워크스페이스는 광고·인앱 결제·토스 로그인이 제한됨(사업자 등록 여부 확인 필요).

## 8. 검수 리스크

| 항목 | 상태 | 대응 |
|---|---|---|
| 카테고리(게임/비게임) | 게임 | 퍼즐이 핵심이라 게임으로 판단됨. 비게임으로 등록해도 검수에서 게임으로 변경됨 |
| 게임 등급분류 | **(확인 필요) — 최대 리스크** | 출시 전 등급분류 증빙 필수: 오픈마켓(구글 플레이 등) 자체등급분류 정보 또는 게임물관리위원회 등급분류증. 비용·기간은 문서에 없음 → GRAC에 직접 확인 |
| 권한 거부 fallback | 해당 없음 | 기기 권한 미사용 |
| 금지 패턴(iframe·eval·SSR·외부 링크) | 해당 없음 | CSR, 외부 이동 없음, 퍼즐 생성 코드에 eval 금지 |
| 프로모션·사행성 요소 | 없음 | 랜덤 보상·포인트 지급을 넣지 않는다 |
| 중복 앱(어뷰징) | 해당 없음 | 퍼즐별로 앱을 나누지 않고 한 앱에 담는다 |
| 상표·디자인 | 주의 | "피크로스" 등 상표명 대신 "노노그램", 기존 지뢰찾기 그래픽 모방 금지 |

## 9. 범위

- v1에 넣는 것: 스도쿠·노노그램·지뢰찾기 각 난이도 2~3단계, 오늘의 세트(날짜 시드), 자유 모드, 이어 풀기, 연속 일수·달력 기록, 사운드·햅틱 설정, 규칙 안내
- v1에서 뺀 것: 리더보드(선택 기능이고 기록 안정화 뒤에), 광고·결제(사업자·약관 필요), 알림(진입 직후 동의 금지 규칙 설계 후), 서버 동기화(서버 필요), 퍼즐 추가 종류(4개째부터는 업데이트로)
- v1 이후 퍼즐 추가 순서(한 앱에 업데이트로, 이름은 일반 명칭만): 이진 퍼즐(Takuzu) → 별 배치(Star Battle) → 라이트업(Akari) → 다리 잇기(Hashi). 이후 후보: 한붓 경로, 텐트, 구역 칠하기, 루프(Slitherlink·Masyu), 요일별 변형 규칙, 주간 메타 퍼즐, 직접 출제한 "오늘의 한 문제"(성냥개비·수열 등)
- 퍼즐 추가 원칙: 문제는 직접 생성(다른 사이트·방송 문제 복제 금지), 상표명(Wordle·Picross·KenKen·Queens·Tango 등)과 방송 프로그램명 사용 금지, 선거·정당 테마 금지(정치 관련 출시 불가). 생성기·검증기는 Simon Tatham's Portable Puzzle Collection(MIT, 저작권 표시 유지)을 참고. WASM으로 넣을 경우 검수 "외부 코드 실행 금지" 해당 여부 (확인 필요)
- 완료 기준: 오늘의 세트 3개를 풀고 앱을 껐다 켜도 진행·연속 일수가 남고, 다음 날 새 세트가 열린다. 게임 출시 가이드 체크리스트를 모두 통과한다.
