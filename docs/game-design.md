# 게임 구성 — 말랑 브레인

작성: 2026-10-23 · 상태: 초안. 판 크기·난이도 수치는 플레이테스트로 조정한다.
PRD(`docs/PRD.md`)의 퍼즐·세트·자유 모드 부분을 자세히 적은 문서다.

## 1. 퍼즐 라인업 (v1, 8종)

퍼즐은 4개 계열로 나눈다. 매일 세트는 서로 다른 계열에서 고른다.

| 계열 | 퍼즐 | 한 줄 규칙 | 조작 | 판 크기 (쉬움/보통/어려움) | 생성 참고 |
|---|---|---|---|---|---|
| 숫자 | 스도쿠 | 행·열·3×3 칸에 1~9를 한 번씩 | 칸 선택 → 숫자 패드, 메모 모드 | 9×9 (단서 수와 필요한 풀이 기법으로 난이도 조절) | Tatham "Solo" |
| 숫자 | 이진 퍼즐 | 0과 1을 같은 개수로, 같은 숫자 3개 연속 금지 | 칸 탭으로 0 → 1 → 빈칸 순환 | 6×6 / 8×8 / 10×10 | Tatham "Unruly" |
| 배치 | 별 배치 | 행·열·구역마다 별 1개, 별끼리 닿지 않게 | 탭: 표시 → 별 → 빈칸 | 5×5 / 7×7 / 8×8 | 자체 구현 (Tatham에 없음) |
| 배치 | 라이트업 | 전구로 모든 칸을 밝히되 전구끼리 비추지 않게 | 탭: 전구 → 표시 → 빈칸 | 7×7 / 8×8 / 10×10 | Tatham "Light Up" |
| 배치 | 텐트 | 나무마다 옆에 텐트 1개, 텐트끼리 닿지 않게 | 탭: 텐트 → 풀 → 빈칸 | 6×6 / 8×8 / 10×10 | Tatham "Tents" |
| 그림·연결 | 노노그램 | 줄 숫자대로 칸을 칠해 그림 완성 | 탭·드래그로 칠하기/X 표시 | 5×5 / 10×10 / 12×12 | Tatham "Pattern" |
| 그림·연결 | 다리 잇기 | 섬 숫자만큼 다리를 놓아 모두 연결 | 섬 두 개를 잇는 드래그, 다시 하면 2개·제거 | 7×7 / 9×9 / 11×11 | Tatham "Bridges" |
| 추론 | 지뢰찾기 | 숫자를 보고 지뢰를 피해 모든 칸 열기 | 탭: 열기, 길게 누르기: 깃발 | 8×8·10개 / 9×12·18개 / 10×16·32개 | Tatham "Mines" (추측 없이 풀리는 판만, 첫 탭 안전) |

- 모든 퍼즐은 **정답이 하나뿐인 판**만 낸다(지뢰찾기는 추측 없이 풀리는 판). 생성기와 검증기를 함께 만든다.
- 목표 풀이 시간: 쉬움 2~3분, 보통 3~5분, 어려움 5~8분. 세트 전체 8~12분(어려움인 토요일은 더 길어도 된다).
- 화면 크기상 노노그램은 12×12, 지뢰찾기는 세로 16줄을 넘기지 않는다.

## 2. 오늘의 세트 — 로테이션 + 요일 난이도

### 구성 규칙

1. 하루 3개, **서로 다른 계열**에서 하나씩.
2. **주 단위 시간표**를 주 시드로 미리 만든다(월~일, 21칸).
   - 8종이 한 주에 각각 2~3번 나온다.
   - 같은 퍼즐이 이틀 연속 나오지 않는다.
3. 요일 난이도:

   | 월 | 화 | 수 | 목 | 금 | 토 | 일 |
   |---|---|---|---|---|---|---|
   | 쉬움 | 쉬움 | 보통 | 보통 | 보통 | 어려움 | 쉬움 |

4. 시드 = 날짜(한국 시간 기준, 자정에 바뀜). 같은 날에는 **모든 사용자가 같은 세트**를 푼다 → 나중에 결과 공유 기능을 붙일 수 있다.
5. 세트 안 순서는 자유. 홈의 "이어 풀기"는 아직 안 푼 첫 퍼즐로 간다.

### 연속 기록

- 그날 세트 3개를 모두 풀면 연속 일수 +1.
- 하루를 건너뛰면 0부터 다시 시작한다.
- 자유 모드와 지난 날 세트는 연속 기록에 들어가지 않는다.

### 구현 메모

- 퍼즐이 아직 다 구현되지 않았으면, 시간표는 구현된 퍼즐만으로 위 규칙을 지켜 만든다. 개발 중에도 세트가 돌아간다.
- 같은 시드는 언제 생성해도 같은 판이 나와야 한다. 생성기는 시드 기반 난수만 쓰고 `Math.random()`을 쓰지 않는다.

## 3. 자유 모드

홈의 "자유 모드"에서 들어간다. 다섯 가지 입구가 있다.

| 입구 | 동작 | 기록 |
|---|---|---|
| 골라 풀기 | 퍼즐 → 난이도 → 새 판. 다 풀면 "한 판 더" | 퍼즐별 기록에 들어감 |
| 무작위 추천 | 한 번 탭하면 퍼즐과 난이도를 골라 줌. "다른 퍼즐" 버튼으로 다시 고르기 | 퍼즐별 기록에 들어감 |
| 지난 날 세트 | 달력에서 최근 30일 중 지난 날짜를 골라 그날 세트를 풂 | 퍼즐별 기록에 들어감, 연속 기록에는 안 들어감 |
| 기록 | 퍼즐별 푼 개수, 난이도별 최고·평균 시간, 세트를 끝낸 날 달력 | — |
| 규칙 연습판 | 퍼즐을 처음 열 때 자동으로 뜨는 작은 판(4×4 안팎) 따라 하기. 이후엔 플레이 화면의 "규칙"에서 다시 볼 수 있음 | — |

### 무작위 추천 규칙

- 최근 7일 동안 덜 푼 퍼즐일수록 더 자주 고른다.
- 난이도는 그 퍼즐에서 최근에 푼 난이도를 기본으로, 연속으로 빨리 풀었으면 한 단계 올린다.
- 아직 연습판을 안 한 퍼즐이 뽑히면 연습판부터 보여 준다.
- 보상·포인트를 걸지 않는다(사행성 요소 없음).

## 4. 결과 공유

세트 3개를 다 풀면 결과 화면에 "공유하기"가 생긴다. 같은 날에는 모두 같은 세트라서, 받은 사람도 같은 퍼즐을 풀어 볼 수 있다.

- 공유 내용: 날짜·난이도, 퍼즐별 풀이 시간, 연속 일수 + 그날 세트로 바로 가는 링크

  ```
  말랑 브레인 10월 23일 (보통)
  스도쿠     5분 12초
  지뢰찾기   2분 40초
  별 배치    3분 05초
  🔥 4일 연속
  <미니앱 공유 링크>
  ```

- 링크: `getTossShareLink('intoss://malrang-brain/set?date=YYYY-MM-DD')`로 만들고 `share({ message })`로 보낸다. 서버는 필요 없다.
- 받은 사람이 링크를 열었을 때:
  - 오늘 날짜면 → 홈(오늘의 세트)
  - 지난 날짜(30일 안)면 → 그날 세트를 지난 날 세트로 연다(연속 기록 미반영)
  - 30일보다 오래됐으면 → 홈으로 보내고 "지난 세트는 최근 30일까지 풀 수 있어요" 안내
- 주의: `intoss://` 링크는 정식 출시 후에만 열린다. 출시 전에는 업로드 때 나오는 테스트 스킴(`intoss-private://…?_deploymentId=…`)으로 확인한다.
- 공유에 보상(포인트·아이템)을 걸지 않는다.

## 5. 개발 순서 (v1 안에서)

1. 공통 틀: 플레이 화면 껍데기(타이머·일시정지·규칙·결과), 시드 난수, 저장, 주간 시간표 + **스도쿠**
2. **이진 퍼즐·텐트** — 규칙과 생성이 단순
3. **지뢰찾기·노노그램**
4. **라이트업·다리 잇기**
5. **별 배치** — 구역 생성과 정답 유일성 검사를 직접 만들어야 해서 마지막
6. 자유 모드 다섯 입구, 홈의 자유 모드 입구 정리
7. 결과 공유
